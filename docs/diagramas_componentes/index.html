Estructura del Diagrama Macro (Plantilla Docente)

Representa los límites de los subsistemas y sus interacciones con el runtime central y dependencias:

  • Dentro del Cuadro (Implementados): Autenticación y Usuarios, Catálogo, Sucursales/Inventario/Proveedores, E-Commerce, Reservas, Punto de Venta (POS).
  • Fuera del Cuadro (Futuros/No implementados): Gestión de Pedidos y Reportes, Inteligencia Artificial y Experiencia del Cliente.
  • Componente Orquestador: <<source>> run.py.
  • Librerías y APIs: FastAPI, psycopg2, Gunicorn, Angular, TailwindCSS, PyJWT, ReportLab, CloudinarySDK, Requests, PayPal API, Cloudinary.
  • Base de Datos: PostgreSQL ("comercio") sobre Oracle Cloud / VPS.
